# 🚀 ASCII Generator — How To Open

## ✅ Fast Windows Method

1. Download the ZIP file.
2. Right-click the ZIP and click **Extract All**.
3. Open the extracted folder.
4. Double-click:

```txt
OPEN_ASCII_GENERATOR.bat
```

5. The ASCII Generator will open in your browser automatically.

## ⚠️ Important

Do **not** run the BAT file from inside the ZIP preview. Extract the ZIP first, then run it.
